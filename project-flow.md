Six steps of data modelling:
1. Problem - define our problem clearly and precisely (What problem are we trying to solve?)
2. Data - understand the data we currently have (What data do we have?)
3. Evaluation - establish the criteria and metrics for success (what exactly is success in case of our project?)
4. Features - which features need to be modelled or engineered, i.e., modifications we might need to make in the dataset to make it compatible for modelling
5. Modelling - selecting and applying the correct ML model
6. Experimentation - analyze the output received thus far and experiment while adhering to the our evaluation criteria

Continue the loop until we reach our target.
